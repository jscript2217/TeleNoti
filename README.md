# TeleNoti (v2.5.0)

[![Android](https://img.shields.io/badge/Android-7.0%2B%20(API%2024%2B)-3DDC84?logo=android&logoColor=white)](https://github.com/jscript2217/TeleNoti)
[![Android 15](https://img.shields.io/badge/Target-Android%2015%20(API%2035)-1428A0)](https://github.com/jscript2217/TeleNoti)
[![Latest Release](https://img.shields.io/github/v/release/jscript2217/TeleNoti?label=Release&color=0088CC)](https://github.com/jscript2217/TeleNoti/releases/latest)

**TeleNoti(텔레노티)** 는 안드로이드 스마트폰에 도착하는 **앱 알림·긴 문자(LMS/MMS)·첨부 이미지·수신 전화**를 내 **텔레그램 봇**으로 실시간 전달해 주고, 텔레그램에서 **카톡·문자 바로 답장**까지 보낼 수 있는 안드로이드 전용 알림 중계 앱입니다.

> **다운로드**: [최신 릴리즈(Releases) 페이지](https://github.com/jscript2217/TeleNoti/releases/latest)에서 `TeleNoti-v2.5.0.apk`를 받아 설치하세요.  
> 기존 TeleNoti(`com.example.telegramalramrelay`)가 이미 설치되어 있다면 삭제하지 않고 **그대로 덮어쓰기 업데이트**해도 봇 토큰·Chat ID·프로필·선택한 앱 목록이 그대로 유지됩니다.

### 이런 분께 특히 편합니다
- 서브폰이나 집에 둔 안드로이드 폰에 오는 **문자·카톡·전화 알림을 메인폰/아이폰/PC 텔레그램으로 한곳에서 받아보고 싶은 분**
- 업무 중 휴대폰을 들지 않고 **PC 텔레그램에서 카톡·문자에 바로 답장**하고 싶은 분
- 부재중으로 남기 전에 **전화가 울리는 순간 발신자 이름과 번호를 바로 알고 싶은 분**

## 한눈에 보는 주요 기능

| 기능 | 설명 |
| --- | --- |
| **실시간 앱 알림 전달** | 선택한 앱의 알림이 뜨자마자 내 텔레그램 봇 채팅방(개인/그룹/채널)으로 즉시 전달합니다. |
| **긴 문자(LMS/MMS) 원문 보강** | 알림창에 `...` 또는 `멀티미디어 메시지`로 줄여져 오는 장문 문자를 문자함에서 전체 원문으로 읽어와 짤림 없이 보냅니다. |
| **이미지(사진) 함께 전송** | 카카오톡 사진 미리보기, CCTV/배달 알림 이미지, MMS 첨부 사진을 자동 압축해 텔레그램 사진으로 전송합니다. |
| **텔레그램 양방향 답장** | 텔레그램에 도착한 카톡·문자 알림(`↩️ 답장 가능`)을 길게 누르거나 스와이프해 **답장(Reply)** 하면 스마트폰에서 그대로 회신됩니다. |
| **수신 전화 즉시 알림** | 전화 벨이 울리는 순간(`RINGING`) 발신자 이름과 번호를 1회 즉시 전송합니다. |
| **Chat ID 프로필 & 2명+ 동시 전송** | 받는 사람/방 이름을 프로필로 저장해 앱별로 편하게 고르거나 2명 이상에게 동시에 알림을 보냅니다. |
| **안정성 & 보안** | Keystore AES-GCM 토큰 암호화, 오프라인 시 자동 재전송 큐, 방해금지 시간대, 중복 알림 억제, 키워드 필터를 지원합니다. |

## 텔레그램에서 받는 메시지 예시

### 1) 일반 앱 · 카카오톡 · 문자 알림
```text
📱 카카오톡
📌 친구 이름
💬 오늘 저녁 7시에 만나요!
🕐 26-11-24 18:10:25
```
- **텔레그램에서 답장하기**: 위 메시지를 **스와이프(또는 길게 누르기 -> 답장)** 해서 `"응 7시에 보자!"`라고 보내면, 휴대폰의 카카오톡/문자 알림으로 자동 회신한 뒤 텔레그램에 **`✅ 답장 전송 완료`** 알림을 보내줍니다.

### 2) 수신 전화 즉시 알림
```text
📞 수신 전화
📌 홍길동 (010-1234-5678)
💬 전화가 걸려오고 있습니다
🕐 26-11-24 18:15:02
```
- 연락처 권한(`READ_CONTACTS`)까지 허용하면 저장된 이름이 함께 표시되고, 번호만 있거나 발신번호 표시 제한 전화도 상태에 맞춰 깔끔하게 안내됩니다.

## 화면별 상세 설명

앱 하단의 **5개 탭(`홈` · `앱 선택` · `설정` · `포맷` · `가이드`)** 으로 모든 기능을 조작할 수 있습니다.

| 하단 탭 | 한 줄 요약 |
| --- | --- |
| **홈** | 지금 알림 전달이 켜져 있는지 실시간 상태를 보고 최근 기록을 확인하는 대시보드 |
| **앱 선택** | 어떤 앱의 알림을 텔레그램으로 보낼지 고르고, 앱별 전용 채팅방/포맷을 정하는 화면 |
| **설정** | 텔레그램 봇 연결, 문자/이미지/답장/전화/필터/방해금지/테마를 설정하는 화면 |
| **포맷** | 텔레그램에 도착할 메시지 모양(템플릿·변수)을 미리보기로 꾸미는 화면 |
| **가이드** | 처음 시작 순서, 갤럭시 One UI 7 설정 방법, FAQ 및 현재 권한 상태를 진단하는 화면 |

### ① 홈 (`홈` 탭)

앱을 켜면 가장 먼저 보이는 **실시간 상태 확인 대시보드**입니다.

- **권한 / 초기 설정 배너**
  - 필수 권한(알림 표시 · 알림 접근 · 배터리 예외)이나 봇 정보, 앱 선택이 비어 있으면 화면 상단에 안내 카드가 자동으로 떠서 **`권한 도우미 열기`** 또는 해당 설정으로 바로 이동할 수 있습니다.
- **실시간 작동 상태 카드**
  - **상태 배너 & 전체 ON/OFF 스위치**: 현재 동작 상태를 색상과 문구로 즉시 보여줍니다.
    - 초록색 **「실시간 포워딩 작동 중」**: 정상 감시 및 전송 중
    - 회색 **「포워딩 일시 중지됨」**: 우측 스위치가 꺼져 있음
    - 주황색 **「방해금지 시간대 적용 중 / 리스너 연결 대기 중 / 봇 미설정」**
    - 빨간색 **「권한 필요 · 포워딩 중단됨」**: 알림 접근 권한 허용 필요
  - **알림 리스너 서비스**: 시스템과 실시간 연결 상태를 표시하며 **`재연결`** 버튼으로 즉시 재바인딩을 요청할 수 있습니다.
  - **상단바 작동 표시 (상주 서비스)**: 켜 두면 스마트폰 상단 상태바에 `텔레노티 · 포워딩 작동 중 (오늘 N건)` 알림이 고정되어, 앱을 열지 않아도 작동 여부를 확인하고 **일시 중지/재개**를 바로 누를 수 있습니다.
  - **활성 기능 배지**: 현재 켜진 핵심 기능(`동시 전송 N명`, `양방향 답장`, `수신 전화 알림`, `이미지 전송`, `긴 문자(LMS/MMS) 보강`, `키워드 필터 ON`, `방해금지`, `중복방지`)이 한눈에 보입니다.
  - **`지금 텔레그램 테스트 전송`**: 홈 화면에서 원터치로 내 텔레그램 봇(다중 기본 수신자 포함)에 테스트 메시지를 보내 연결을 확인합니다.
- **최근 알림 (최대 50건)**
  - 최근 전달된 알림의 앱 아이콘, 제목, 본문, 시간, 전송 대상(`→ 아내`), 전송 결과를 보여줍니다.
  - 카톡/문자처럼 텔레그램 답장이 가능한 알림에는 **`↩️ 답장 가능`** 배지가 붙습니다.
  - 인터넷 끊김 등으로 실패한 항목이 있으면 **`실패 재전송`** 버튼으로 한 번에 다시 보낼 수 있습니다.

### ② 앱 선택 (`앱 선택` 탭)

텔레그램으로 전달할 앱을 고르는 화면입니다.

- **검색창**: 앱 이름뿐 아니라 패키지명(`com.kakao.talk` 등)으로도 검색할 수 있으며, 검색 시에는 **시스템 앱까지 모두 포함해** 찾아줍니다.
- **보기 필터 3종**
  - **`일반 앱`**: 런처 아이콘이 있는 일반 사용자 앱 위주로 깔끔하게 표시합니다.
  - **`시스템 앱 포함`**: 전화·메시지·시스템 서비스 등 기본 화면에 숨겨진 앱까지 전부 표시합니다.
  - **`최근 알림 온 앱`**: 실제로 내 폰에 알림을 한 번이라도 띄웠던 앱만 모아 보여줍니다. 목록에 안 보이는 앱도 알림이 한 번 오면 여기에 자동으로 기록됩니다.
- **`+ 직접 추가`**: 목록에서 찾기 어려운 앱도 패키지명을 직접 입력해 추가할 수 있습니다.
- **앱별 맞춤 설정 (우측 슬라이더 아이콘)**
  - 체크한 앱 옆의 **맞춤 설정 아이콘**을 누르면, 저장된 **수신자 프로필을 터치로 1명 또는 여러 명(2명+ 동시 전송)** 고르거나 쉼표(`,`)로 Chat ID를 직접 입력할 수 있고, 앱별 전용 메시지 포맷도 따로 지정할 수 있습니다.
- *(참고: 무한 루프를 막기 위해 TeleNoti 자신과 텔레그램 앱들은 선택 목록에서 자동으로 제외됩니다.)*

### ③ 설정 (`설정` 탭)

텔레그램 봇 연결부터 세부 동작까지 모두 제어하는 화면입니다.

#### 1) 봇 연결 정보 & 수신자 프로필 관리
- **`Bot Token` / `기본 Chat ID (쉼표로 여러 명 가능)`**: 텔레그램 `@BotFather`에서 받은 토큰과 받을 채팅방 ID(쉼표로 여러 명 입력 가능)를 입력합니다.
- **`Chat ID 자동 가져오기 (/start 후 클릭)`**: 숫자 ID를 직접 찾을 필요 없이, 내 봇(또는 봇을 초대한 그룹방/채널)에 메시지나 `/start`를 한 번 보낸 뒤 이 버튼을 누르면 **기본 ID 입력** 또는 **프로필로 저장**을 바로 선택할 수 있습니다.
- **`수신자 프로필 관리 (사람·채팅방별)`**: 자주 보내는 가족·동료·그룹방을 이름(예: `나`, `아내`, `회사 단톡방`)으로 저장하고 개별 테스트 전송·수정·삭제를 할 수 있습니다. 프로필 카드의 **`기본 동시전송`** 칩을 켜 두면 모든 일반 알림·수신 전화 알림이 기본 ID와 해당 프로필 모두(2명 이상)에게 동시에 전송됩니다.
- **`저장` / `테스트 메시지`**: 입력한 토큰과 Chat ID를 Android Keystore AES-GCM으로 암호화해 안전하게 저장하고 테스트 메시지를 보냅니다.

#### 2) 필터 및 스케줄
- **`긴 문자(LMS/MMS) 원문 보강`**: 문자 앱 알림이 짧게 잘려 올 때 `READ_SMS` 권한으로 문자함에서 전체 긴 내용과 첨부 이미지를 함께 가져옵니다.
- **`이미지(사진) 함께 전송`**: 알림에 포함된 미리보기 사진이나 MMS 사진을 텔레그램으로 함께 보냅니다.
- **`텔레그램에서 바로 답장 (카톡·문자)`**: 텔레그램 스와이프 답장 수신(Long Polling)을 켜서 카톡·문자에 바로 회신할 수 있게 합니다. *(상주 서비스 ON 권장)*
- **`수신 전화 즉시 알림`**: 전화가 걸려오는 순간 발신자 이름·전화번호를 즉시 텔레그램으로 보냅니다.
- **`키워드 필터`**: 쉼표(`,`)로 구분해 **포함 키워드**(예: `입금, 인증번호, 택배`)나 **제외 키워드**(예: `광고, 홍보`)를 지정할 수 있습니다.
- **`방해금지 시간대`**: 지정한 시작~종료 시각 사이에는 알림과 전화 중계를 멈춥니다. (야간 시간대 예: `23:00 ~ 07:00` 지원)
- **`진행 중(상단바 고정) 알림 제외`**: 음악 재생, 타이머, 파일 다운로드처럼 계속 떠 있는 고정 알림을 무시합니다.
- **`중복 알림 방지`**: `끄기 / 3초 / 5초 / 10초 / 30초` 중 선택해 똑같은 연속 알림이 여러 번 전송되지 않게 막습니다.
- **`일일 통계 자동 초기화`**: 매일 지정한 시각(기본값 **자정 `00:00`**)에 오늘 전송 카운트를 `0`으로 초기화합니다.

#### 3) 권한, 서비스 및 화면
- **`권한 설정 도우미 열기 (단계별 안내)`**, **`알림 접근 권한`**, **`배터리 예외 등록`**, **`백그라운드 상주 서비스`** 제어
- **`화면 테마`**: `시스템 설정` / `라이트` / `다크` 선택
- *(예기치 못한 앱 오류 발생 시 `마지막 크래시 로그 보기`가 나타나 원인을 복사·확인할 수 있습니다.)*

### ④ 포맷 (`포맷` 탭)

텔레그램으로 날아오는 메시지 형태를 취향에 맞게 바꾸는 화면입니다.

- **프리셋 템플릿 4종**: **`기본 (추천)`** / `간단` / `상세` / `최소` 중 터치 한 번으로 고를 수 있습니다.
- **변수 터치 추가**: `{app}`(앱 이름), `{title}`(제목), `{text}`(본문), `{time}`(시간), `{package}`(패키지명) 버튼을 누르면 커스텀 포맷 끝에 바로 추가됩니다.
- **실시간 미리보기**: 카카오톡 예시 문구로 실제 텔레그램에 어떻게 보일지 아래 카드에서 즉시 확인하고 저장할 수 있으며, 언제든 **`기본 형식으로 되돌리기`** 로 복구할 수 있습니다.

### ⑤ 가이드 (`가이드` 탭) & 권한 설정 도우미

- **1. 처음 시작하기 (4단계)** · **2. Android 13~15 · 갤럭시(One UI) 필수 설정** · **3. 긴 문자/이미지 안내** · **4. 자주 묻는 질문(FAQ)** 을 앱 안에서 바로 확인할 수 있습니다.
- **5. 현재 앱 상태 진단**: 앱 버전, Android OS 버전, 알림 표시/알림 접근/배터리 예외/SMS/수신 전화 권한 허용 여부와 리스너·상주 서비스 작동 상태를 한눈에 진단합니다.

#### 권한 설정 도우미 (1~6단계 체크리스트)
홈/설정/가이드 화면에서 **`권한 설정 도우미`** 를 열면 아래 권한을 순서대로 안내받으며 한 번에 설정할 수 있습니다:

| 단계 | 권한 | 구분 | 용도 |
| --- | --- | --- | --- |
| **1. 알림 표시 권한** | `POST_NOTIFICATIONS` | 필수 | 상단바에 포워딩 작동 상태 알림 표시 |
| **2. 알림 접근 권한** | 알림 리스너 | 핵심 필수 | 다른 앱의 알림 내용을 읽어 텔레그램으로 전달 |
| **3. 배터리 최적화 예외** | 배터리 제한 없음 | 권장 | 화면이 꺼져도 백그라운드에서 끊김 없이 동작 |
| **4. 상단바 작동 표시** | 상주 서비스 (`specialUse`) | 추천 | 상태바 작동 표시 및 텔레그램 양방향 답장 안정화 |
| **5. 긴 문자 원문 보강** | `READ_SMS` | 선택 | 잘린 LMS/MMS 문자의 전체 내용과 첨부 이미지 조회 |
| **6. 수신 전화 즉시 알림** | `READ_PHONE_STATE` · `READ_CALL_LOG` · `READ_CONTACTS` | 선택 | 전화 벨이 울리자마자 발신번호와 연락처 이름 즉시 전송 |

> **One UI 7 빠른 설정창(퀵 패널) 타일 지원**: 상단 빠른 설정창 편집(`✏️`)에서 **`텔레노티`** 버튼을 추가하면 앱을 열지 않고도 포워딩 ON/OFF와 작동 상태를 바로 확인·전환할 수 있습니다.

## 5분 만에 따라 하는 처음 설정

### 1단계. 텔레그램 봇 만들고 연결하기
1. 텔레그램에서 **`@BotFather`** 를 검색해 `/newbot` 을 입력합니다.
2. 봇 표시 이름과 아이디(반드시 `bot`으로 끝나야 함, 예: `my_telenoti_bot`)를 정하면 **Bot Token**(`숫자:영문문자열`)이 발급됩니다.
3. 방금 만든 내 봇 채팅방(`t.me/내봇아이디`)으로 들어가 **`시작(/start)`** 버튼을 한 번 누릅니다. *(그룹방·채널로 받으려면 해당 방에 봇을 초대한 뒤 메시지를 1번 보내세요.)*
4. TeleNoti **`설정`** 탭 -> `Bot Token` 붙여넣기 -> **`Chat ID 자동 가져오기`** 클릭 -> 내 방 선택 -> **`저장`** 후 **`테스트 메시지`** 로 도착을 확인합니다.

### 2단계. Android 13~15 · 갤럭시(One UI) 필수 설정 2가지
1. **「제한된 설정」 때문에 알림 접근 / 전화 권한이 막힐 때**
   - Play 스토어가 아닌 APK 파일로 직접 설치하면 Android 13~15 보안 정책상 처음에 스위치가 회색으로 잠길 수 있습니다.
   - **해결**: `권한 설정 도우미` 안의 **`앱 정보 열기`** 클릭 -> 우측 상단 **`⋮`** 메뉴 -> **`제한된 설정 허용`** 클릭 -> 다시 돌아와 알림 접근 및 권한을 켜면 바로 허용됩니다.
2. **화면이 꺼져도 딜레이 없이 받기**
   - **앱 정보 -> 배터리 -> `제한 없음`** 선택
   - **설정 -> 디바이스 케어 -> 배터리 -> 백그라운드 사용 제한 -> `절전 예외 앱`에 TeleNoti 추가**
   - 홈 탭에서 **`상단바 작동 표시 (상주 서비스)` ON**

## 자주 묻는 질문 (FAQ)

- **Q. 텔레그램에서 카톡/문자 답장이 안 될 때는 어떻게 확인하나요?**
  - 카카오톡 앱 설정에서 알림 내용이 **「이름 + 메시지」** 로 되어 있어야 알림에 답장 기능이 붙습니다. 또한 TeleNoti `설정` 탭에서 `텔레그램에서 바로 답장`과 홈 탭의 `상주 서비스`를 켜 두셔야 화면이 꺼진 상태에서도 답장 명령을 바로 받습니다. *(단, 휴대폰을 재부팅하거나 앱을 재시작하기 전에 온 알림은 OS 정책상 답장이 불가능합니다.)*
- **Q. 전화가 올 때 텔레그램으로 대신 받을 수도 있나요?**
  - Android 10 이후 OS 보안 정책상 일반 앱이 통화 음성을 텔레그램으로 중계하거나 대신 받아 안내 멘트를 송출하는 기능은 시스템에서 차단되어 있습니다. 대신 TeleNoti는 벨이 울리자마자 **발신자 이름과 번호를 1회 즉시 텔레그램으로 알려주는 기능**을 제공합니다.
- **Q. 기존 TeleNoti(`1.0.0`)에서 업데이트했는데 봇 토큰이 그대로 남아있나요?**
  - 네. 같은 서명 키로 빌드된 릴리즈 APK를 덮어쓰기 설치하면 기존 `botToken`, `chatId`, 선택한 앱 목록이 자동 유지되며 암호화 저장소로 안전하게 이관됩니다.
- **Q. 아이폰(iOS)에서도 똑같이 만들 수 있나요?**
  - Apple iOS는 다른 앱의 알림을 읽거나 SMS/전화 발신번호에 접근하는 API를 허용하지 않아 동일 기능의 iOS 앱은 제작할 수 없습니다. 대신 **서브폰(갤럭시)에 TeleNoti를 켜 두고, 아이폰에서는 일반 텔레그램 앱만 쓰시면** 모든 알림 수신과 카톡/문자 답장까지 그대로 사용하실 수 있습니다.

### 1) GitHub Actions 자동 릴리즈 (`.github/workflows/release.yml`)

`v*` 태그를 푸시하거나 GitHub **Actions -> Release APK -> Run workflow**를 수동 실행하면 자동으로 유닛 테스트(`testDebugUnitTest`) 통과 후 APK와 `SHA256SUMS.txt`를 GitHub Releases에 업로드합니다.

#### GitHub Secrets 4종 등록 (기존 앱 업데이트 서명 유지용)
PowerShell에서 로컬 키스토어(`jks\dddd`)를 Base64로 클립보드에 복사합니다:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes("jks\dddd")) | Set-Clipboard
```

저장소 **Settings -> Secrets and variables -> Actions -> New repository secret**에 아래 4개를 등록합니다:

| Secret 이름 | 설명 |
| --- | --- |
| `KEYSTORE_BASE64` | 위 PowerShell 명령으로 복사한 Base64 문자열 |
| `KEYSTORE_PASSWORD` | 키스토어(`jks/dddd`) 비밀번호 |
| `KEY_ALIAS` | 키스토어 내 인증서 alias (`key0`) |
| `KEY_PASSWORD` | 키 비밀번호 |

- **4개 Secrets 모두 등록 시**: 서명된 `TeleNoti-<태그>.apk` 생성 및 업로드
- **Secrets 미등록 시**: 폴백으로 `TeleNoti-<태그>-debug.apk`와 `TeleNoti-<태그>-release-unsigned.apk` 생성

#### 릴리즈 실행
```bash
git add .
git commit -m "Release v2.5.0"
git push origin master
git tag v2.5.0
git push origin v2.5.0
```
또는 GitHub **Actions -> Release APK -> Run workflow**에서 `tag_name`을 입력해 실행합니다.

### 2) 로컬 환경 직접 빌드

프로젝트 루트에 `keystore.properties`를 생성하거나(`.gitignore`로 Git 추적 제외) 환경 변수(`ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`)를 지정해 빌드합니다.

```properties
storeFile=jks/dddd
storePassword=YOUR_KEYSTORE_PASSWORD
keyAlias=key0
keyPassword=YOUR_KEY_PASSWORD
```

```powershell
.\gradlew.bat testDebugUnitTest assembleRelease --no-daemon
```

- 출력 위치: `app/build/outputs/apk/release/app-release.apk`

### 3) 원격 저장소 히스토리 보안 참고
- 최신 커밋에서는 `jks/dddd`, `local.properties`, 빌드 산출물을 Git 추적에서 제거(`git rm --cached`)하고 `.gitignore`에 등록했습니다.
- 만약 과거 `1.0.0` 원격 커밋 히스토리에 `jks/dddd`가 남아 있는 상태를 완전히 정리하고 싶다면 `git filter-repo` 등으로 과거 히스토리를 정리하거나 비공개 저장소/새 서명 키 전환을 권장합니다.
